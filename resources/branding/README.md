# Branding assets

Originals are stored unmodified in `originals/`. Derived files are generated from them;
never overwrite an original.

| Original | Source | Derived | Use |
|---|---|---|---|
| `originals/logo-silver-original.png` | user, 2026-11-06 | `logo-silver.png` (alpha >=16 visible bounds + 8px margin) | enlarged interface wordmark, light-on-dark use |
| `originals/icon-mark-original.png` | user, 2026-11-06 | `icon-mark-1024.png` (trimmed, square canvas) | icon variant A, flat mark |
| `originals/icon-tile-original.png` | user, 2026-11-06 | `icon-tile-1024.png`, `icon-header.png` | previous app icon, retained; header mark retained but no longer displayed |
| `originals/icon-glossy-chevron-original.png` | user, 2026-11-08, `Глянцевый значок с голубым шевроном.png` | `icon-glossy-chevron-1024.png` (complete canvas), `icon-windows-1024.png` and `icon-window-256.png` (trimmed, 2 % margin) | selected application icon |

All originals are 8-bit RGBA PNG with a transparent background.

The app icon uses the user-selected glossy silver tile with a blue chevron. Its original is preserved
byte-for-byte at 1254×1254; the 1024×1024 derivative uses Pillow LANCZOS resizing of the complete
canvas, without cropping, background replacement or redrawing. JUCE generates the macOS icon from this
PNG through `ICON_BIG` in `CMakeLists.txt`. The interface wordmark is unchanged; earlier icon variants
remain available and are not deleted.

The original canvas is inset: the mark occupies about 75 % of it. Apple's grid expects that inset, so
the macOS file keeps it. A Windows shell icon is drawn at 16-48 px next to icons that fill their box,
and the same artwork then reads as smaller than its neighbours; `ICON_BIG` therefore points at
`icon-windows-1024.png` on Windows, and the runtime window icon (`icon-window-256.png`, used for the
taskbar button) is the same trim. Both are generated by `make-icon.py` from the preserved original:
alpha >=16 bounds, a square canvas, a 2 % margin, so the mark fills about 94 % across. Rebuild after
changing the original; `TestUI` fails when the window icon's mark does not reach 90 % of the canvas.
