### Исправления по замечаниям владельца

- [x] При выносе региона за окно с Loop — «Отключите луп», без внешнего drag;
      подсказка не затирается таймером. Движение/resize внутри окна сохранены.
- [x] Interface scale доступен в плагине; масштабируется весь интерфейс и текст,
      размер окна меняется пропорционально; глобальный масштаб DAW не меняется.
- [x] Support: ko-fi и Boosty друг под другом.
- [x] Close добавлена в иерархию Settings, видима и закрывает окно.
- [x] Длинный заголовок группы контекстного меню заменён на Processing.

Регрессии: `[acceptance-fixes]` в `TestPlugin.cpp`, `TestSelection.cpp`,
`TestSettingsNavigation.cpp`. Снимки реальных компонентов General/About на 100% и 125%
создаются тестом при `SONICATOR_PLUGIN_SCREENSHOT_DIR=<папка>`; в репозиторий личные окна
не попадают. Повторная ручная проверка владельцем в DAW ещё требуется.

Локальная проверка исправлений: 5 новых регрессионных случаев (35 assertions), полный
Debug `ctest` — pass; universal приложение/VST3/AU собраны, подписи `codesign --verify --deep
--strict` и архитектуры arm64+x86_64 проверены. Просмотрены снимки General/About 100% и 125%.
