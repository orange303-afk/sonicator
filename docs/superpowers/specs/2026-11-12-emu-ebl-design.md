# ТЗ: сэмплы E-mu Emulator X (`.ebl`) как обычные аудиофайлы библиотеки

Дата: 2026-11-12. Статус: на утверждение.
При реализации этот файл копируется в `docs/superpowers/specs/2026-11-12-emu-ebl-design.md`.

## Зачем

Бэклог предлагает использовать samplerdisc (github.com/bmxcode/samplerdisc, MIT, Python)
для экзотических форматов. Решение уже принято: форматы переносятся в C++, а samplerdisc служит
**спецификацией** (`docs/formats/*.md`) и **эталоном** для побайтной сверки. Python в приложение
не встраивается и не вызывается.

Первым идёт формат, по которому у пользователя больше всего материала: 13 156 файлов `.ebl`
в 18 банках `/Volumes/1TBSSD/samples/E-MU Sound Sets/<Банк>.exb/SamplePool/` (Proteus 1–3,
Planet Phatt, Orbit, Mo'Phatt, Vintage Pro, SP-1200 и др.). Сейчас Sonicator их не видит.
Цель — чтобы эти сэмплы стали обычными сэмплами библиотеки: сканировались, слушались,
анализировались и перетаскивались в DAW.

## Что такое `.ebl` (по samplerdisc `docs/formats/emu-ebl.md` и `sample/emu_ebl.py`)

Один файл — один сэмпл. Внутри IFF `FORM` с внешними заголовками в big-endian и данными
в little-endian:

- `0x00 FORM`, `0x08 E5B0TOC2`, `0x14 E5S1`. По смещению `0x1C` лежит big-endian абсолютное
  смещение второй секции `E5S1`. Блок описания данных начинается с `second + 14` и занимает
  176 байт. В нём:
  - имя: 64 байта UTF-16LE;
  - `V2`: блок + 68;
  - `V3`: блок + 72;
  - частота: блок + 100;
  - `V12`: блок + 108;
  - комментарий: 64 байта UTF-16LE.
- Каналы определяет байт `(V12 >> 16) & 0xFF`. Значение `0x03` — стерео, любое другое
  (`0x01`, `0x02`) — моно. Сравнивать надо именно на равенство `0x03`.
- Начало звука: `блок + V2 − 4`. Конец: начало трейлера `EXLZ` (если в нём есть полный `MARK`),
  иначе конец файла. Длина обрезается до целого числа сэмплов.
- Стерео хранится блоками: сначала весь левый канал, затем весь правый (`LLLL…RRRR`).
  Длина канала `V3 − V2`. Левый блок начинается с `конец − 2·(V3−V2)`, то есть отсчёт идёт
  **от конца**: передний якорь на части банков ошибается на 2 байта. Если файл обрезан и такой
  старт залезает в блок описания, делим пополам с переднего якоря.
- PCM — signed 16-bit LE, частота берётся из записи. Встречаются 282 разных значения
  (44 001, 47 360, 24 000…), их не округлять.
- Петля: `MARK`, за ним старт и конец в кадрах (LE), конец не включается. Если петля не
  выполняется условием `0 ≤ start < end ≤ frames`, она отбрасывается.
- Файл `.exb` (определение банка с пресетами и зонами) не читается.
- Пример у пользователя: `Orbit 8080SL289.ebl`, в заголовке имя `org nod C +36`.

## Цели

1. **Декодер `.ebl` на C++** по правилам выше. Повреждённый файл отклоняется с понятной
   причиной; никаких падений, никаких чтений за границей файла.
2. **Обычный аудиоформат.** `.ebl` открывается через тот же `juce::AudioFormatManager`, что
   WAV/AIFF. Тогда автоматически работают:
   - скан с полным анализом (длительность, частота, каналы, пики, признаки);
   - smart-анализ;
   - волна и прослушивание;
   - MIDI-превью;
   - выделение и экспорт фрагмента;
   - Split.
   Регистрация делается в одной функции, её вызывают все места, которые сейчас вызывают
   `registerBasicFormats()`.
3. **Имя из заголовка.** В каталоге строка `.ebl` называется именем из заголовка
   (`org nod C +36`), а не порядковым именем файла (`Orbit 8080SL289.ebl`). По этому имени
   работает поиск. Путь к файлу не меняется. Если имя в заголовке пустое, остаётся имя файла.
4. **Перетаскивание в DAW отдаёт WAV.** Строка `.ebl`, перетащенная из списка, превращается
   в WAV во временной папке перетаскивания. В этом WAV:
   - тот же PCM, частота и каналы;
   - петля, если она есть, записана в `smpl`.
   Остальные строки перетаскиваются как сейчас.
5. **Эталонная сверка.** Opt-in тест сравнивает декодированный PCM с WAV, которые выдаёт
   `uvx samplerdisc extract-banks`, на банках пользователя. Требование: побайтное совпадение.
6. **Документация и авторство.**
   - Файл `docs/EMU_EBL.md`: формат, результаты сверки, ссылка на samplerdisc.
   - Запись в `THIRD_PARTY_NOTICES.md`: знание формата из samplerdisc (MIT), код не копируется.
   - Бэклог: строка про samplerdisc получает отметку «◐ этап 1: E-mu EBL».

## Не входит в этап

- Пресеты, зоны и кейгруппы из `.exb`: играемые инструменты — отдельная задача.
- Контейнеры MDX, NRG, MDS/MDF и файловые системы EMU3, Roland S-7xx, Kurzweil KMSI.
  Следующие этапы, ближайший — MDX.
- Отдельные файлы Kurzweil `.krz`: samplerdisc их не читает, это отдельная задача.
- Корневая нота и петли в столбцах каталога: для них нет полей.
- Пакетная конвертация в WAV (пункт «конвертер форматов» в бэклоге).
- Name-эвристики AutoTag и smart, которые разбирают имя файла из пути. Они видят
  `Orbit 8080SL289` и продолжат его видеть.

## Анти-цели

- Изменение исходных `.ebl`.
- Python в сборке приложения или в обязательных тестах. Эталонная сверка только opt-in.
- Угадывание раскладки: стерео определяется только по `V12`, длина — только по
  трейлеру или концу файла.
- Падение или чтение за пределами файла на повреждённых данных.
- Регресс существующих форматов при замене `registerBasicFormats()`.

## Критерии приёмки

1. Юнит-тесты на синтетических `.ebl`:
   - моно с паддингом 8 и петлёй;
   - моно с паддингом 4 без петли;
   - моно с байтом `0x02`;
   - стерео с якорем от конца (тестовый файл устроен так, что передний якорь даёт другой
     результат);
   - обрезанное стерео (запасной вариант с делением пополам);
   - отказы: не `FORM`, нет `E5B0TOC2`, вторая секция не там, блок за пределами файла,
     нулевая частота;
   - петля вне диапазона отбрасывается.
2. `AudioFormatManager`, собранный через общую регистрацию, открывает `.ebl`: кадры, частота
   и каналы совпадают с декодером, значения совпадают с точностью до 1/32768.
   `FileScanner::isSupportedFormat(.ebl)` возвращает true, `isMetadataOnlyFormat` — false.
3. Индексация папки с синтетическими `.ebl` на временной базе: строки с именем из заголовка,
   длительностью и частотой, анализ без ошибок.
4. Перетаскивание: путь к `.ebl` превращается в существующий WAV с тем же PCM и с `smpl`,
   если у файла есть петля.
5. Opt-in `[.ebl-corpus]` (`SONICATOR_EBL_DIR`): **все** `.ebl` в
   `/Volumes/1TBSSD/samples/E-MU Sound Sets` декодируются, отказы печатаются с причинами.
   Без объяснения допустимо 0 отказов. Если отказы будут, это стоп-условие.
6. Opt-in `[.ebl-reference]` (`SONICATOR_EBL_DIR`, `SONICATOR_EBL_REFERENCE`): для каждого
   WAV из samplerdisc, найденного по имени, PCM совпадает побайтно, расхождений 0.
   Сопоставляется не меньше 90 % файлов банка, неоднозначные имена считаются отдельно.
7. Полный `ctest` зелёный. В приложении вручную: папка `E-MU Sound Sets` сканируется, сэмпл
   играет, перетаскивание в Finder даёт WAV.

## Стоп-условия (вернуться к пользователю)

- У пользователя есть `.ebl`, которые декодер отклоняет, а samplerdisc читает.
- PCM расходится с samplerdisc хотя бы на одном однозначно сопоставленном файле.
- Замена `registerBasicFormats()` меняет поведение хотя бы одного существующего теста.
