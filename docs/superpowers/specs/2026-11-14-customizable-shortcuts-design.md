# Переназначаемые горячие клавиши — план и ТЗ

Дата: 2026-11-14. Статус: проектное ТЗ будущей функции; реализация не начата.

## Цель

Пользователь может назначить клавиатурное сочетание на **любое действие Sonicator, имеющее явную команду**: от `Select All` до редактирования волны (`Trim Silence`, `Normalize`), повторения последнего тега (`Add Last Tag`) и сохранения (`Save`, `Save Copy`, `Save and Overwrite`). Настройка живёт в Settings → Keyboard Shortcuts и сохраняется между запусками. Новые действия, включая команды пользовательских компонентов, регистрируются в том же каталоге.

Под «всеми возможными действиями» понимаются действия меню, кнопок и контекстных меню, которые можно безопасно вызвать как команду. Непосредственные жесты мыши и ввод значений внутри текстового поля не превращаются в отдельные команды. Реестр должен показывать полный список доступных команд, а не фиксированный вручную перечень горячих клавиш.

## Каталог команд

Каждая команда имеет стабильный ID, локализованное имя и описание, категорию, контекст, состояние `available/enabled`, обработчик и набор стандартных сочетаний для macOS/Windows. Команда выполняется через один обработчик независимо от того, вызвана ли она меню, кнопкой или клавишей. Переименование надписи не меняет ID и пользовательскую привязку.

Примеры категорий и команд:

| Категория | Примеры |
|---|---|
| Library | Select All, Clear Selection, Copy Path, Add/Remove Favorite, Search, Analyze Selected, Show in Finder/Explorer |
| Tags/metadata | Add Last Tag, Add Tag…, Remove Tag…, Set Type…, Set Genre… (после реализации Genre) |
| Preview | Play/Pause, Stop, Loop, Next/Previous Sample, Seek, Toggle MIDI Preview |
| Waveform edit | Undo, Redo, Delete Region, Crop, Reverse, Fade In/Out, Normalize, Gain…, Convert to Mono, Remove DC, Trim Silence |
| File/output | Save, Save Copy, Save and Overwrite, Extract…, Convert… (после реализации конвертера) |
| App/navigation | Settings, switch panel/view, rescan, New Files, focus search |
| User components | Команды, объявленные установленным компонентом; ID включает ID компонента |

`Add Last Tag` использует последний **успешно применённый** тег в текущем каталоге. Если такого тега нет, команда неактивна. Для нескольких выбранных файлов она применяет этот тег ко всем. Уточнить при реализации, должен ли «последний» быть общим для каталогов или отдельным для каждого; безопасный исходный выбор — отдельным.

`Save and Overwrite` — явная команда, отличная от обычного `Save`, которое может открыть выбор `Overwrite / Save Copy / Cancel`. Она доступна только когда текущий формат и объект допускают перезапись; перед первым использованием или по настройке пользователя может потребоваться подтверждение. Она обязана использовать тот же безопасный путь записи, что и обычный диалог сохранения. Для несохранённых правок в неподдерживаемом формате команда неактивна.

## Settings → Keyboard Shortcuts

- Поиск по названию, описанию и ID; группировка по категориям; отображение текущего и стандартного сочетания, контекста и источника команды.
- Нажатие на строку → `Record shortcut`: приложение захватывает следующее сочетание, показывает его в платформенном написании (`⌘` на macOS, `Ctrl` на Windows), затем предлагает применить. Действия `Remove`, `Reset this command`, `Reset all`, экспорт/импорт схемы — по этапам; минимум первые три в первой версии.
- Допускать несколько сочетаний для одной команды и пустую привязку. Поддержать обычные комбинации модификаторов и клавиши; многоклавишные последовательности рассмотреть позже.
- При конфликте показать обе команды и контексты. В одном контексте нельзя молча назначить сочетание дважды: предложить заменить старую привязку или отменить. Для непересекающихся контекстов одинаковое сочетание допустимо.
- Не назначать глобальные системные сочетания за пределами окна Sonicator. Текстовые поля сохраняют системные операции ввода (`Copy`, `Paste`, `Select All`, Undo`) с обычным приоритетом; например, `Select All` в поиске выделяет текст, а в библиотеке — строки.
- Меню и подсказки показывают фактически назначенные сочетания. После изменения привязки UI обновляется без перезапуска.

## Контексты и выполнение

Контексты: приложение в целом, библиотека, дерево папок, предпросмотр, редактор волны, диалог, активное текстовое поле. Команда проверяет предусловия в момент вызова: выбранные файлы, открытый редактируемый источник, наличие несохранённых правок, запущенное задание, права записи и т. п. Неактивное действие не вызывает скрытую операцию; интерфейс может объяснить причину.

Приоритет: активный диалог/поле ввода → сфокусированная панель → окно приложения. `Escape`, `Return`, `Space`, стрелки и Delete требуют особой проверки, поскольку уже используются для навигации, воспроизведения и кнопок диалогов. Пользовательский компонент не может перехватывать ввод раньше активного диалога или системных текстовых операций.

## Данные и совместимость

Привязки хранить в пользовательских настройках как отображение стабильного ID команды на платформенные сочетания, с версией схемы и атомарной записью. Неизвестные ID (например, удалённого компонента) не исполняются; при повторной установке совместимого компонента привязка может восстановиться. При изменении стандартной схемы пользовательские назначения остаются прежними. Профиль macOS и Windows хранить раздельно либо переносить с явным преобразованием `Cmd`/`Ctrl`, не угадывая молча.

Сейчас обработка клавиш распределена между `MainComponent`, `PreviewPanel`, браузером дисков и диалогами. Сначала инвентаризировать существующие действия и обработчики, затем свести пользовательские команды в единый реестр, не ломая ввод текста и клавиши навигации. Существующая безопасность операций сохранения/перезаписи остаётся обязательной.

## Этапы

1. Составить полный инвентарь действий, стандартных сочетаний и контекстов; дать каждому стабильный ID. Отдельно проверить операции с записью файлов.
2. Реализовать реестр команд и единый вызов через UI и клавиатуру; мигрировать существующие клавиши без изменения поведения по умолчанию.
3. Добавить Settings → Keyboard Shortcuts, запись сочетаний, конфликты, сброс и сохранение.
4. Добавить команды редактора, тегов, файловых операций и `Add Last Tag`; интегрировать будущие Genre, Convert и пользовательские компоненты по мере их появления.
5. Проверить работу на macOS/Windows, включая разные раскладки клавиатуры, активные диалоги и поля ввода.

## Критерии приёмки

- Любое зарегистрированное действие видно в Settings; привязку можно назначить, удалить и сбросить, изменения переживают перезапуск.
- `Select All` действует на сфокусированную область: в библиотеке — строки, в поле поиска — текст.
- `Trim Silence` и `Normalize` вызывают те же операции, что меню редактора, и недоступны без редактируемого аудио.
- `Add Last Tag` применяется к выделению только при наличии последнего тега; ручные теги и другие метаданные сохраняются.
- `Save and Overwrite` недоступен там, где перезапись запрещена, и не обходит безопасную запись или правила подтверждения.
- Конфликт одинаковых сочетаний в одном контексте разрешается явно; команда стороннего компонента исчезает при выключении компонента, не перехватывая клавиши.
- Набор стандартных действий, текстовый ввод и навигация работают без регрессий после миграции.
