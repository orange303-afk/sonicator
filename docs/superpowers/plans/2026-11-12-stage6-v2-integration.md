# Этап 6: интеграция v2 — план

Источник: `docs/superpowers/specs/2026-11-12-feature-schema-2-public-datasets-design.md` §8.
Решение владельца 2026-11-12: этап начинается, несмотря на невыполненные критерии (4) и точности;
глобальная модель поставляется как cold start, локальная v2 — как основной путь (78.1% против 76.8%).

## Требования

- Схема БД 16: `ml_feedback_samples.feature_schema` (1 или 2) и `features_v2 BLOB`.
- Старые строки остаются на схеме 1 и работают; пересчёт v2 — фоновая задача, отменяемая, без
  повторного декодирования одного файла.
- Сравнение сходства только внутри одной схемы; v2 сравнивается по `featureIndices` модели.
- Загрузка `resources/ml/global_model.json` (M2): `mu`, `sd`, `W`, `b`, `labels`, `temperature`,
  `similarityMap`, `groups`, `datasets`, `generatedAt`. Битый файл и чужая схема отвергаются.
- Резолвер: источник `global_model` в группе `adaptive`; приоритет ниже `user_adaptive`, выше `path`.
- Вклады: `featureSchema: 2`, экспорт и воркер принимают обе схемы; согласие 4.
- About: дата модели, число меток, строка атрибуции датасетов.
- `resources/` меняется только здесь: файл модели и бинарные данные.

## Задачи

- [ ] 1. Схема 16 и репозиторий: колонки, `FeedbackRecord::featureSchema/featuresV2`,
      `setFeedbackV2`, миграция 15→16 без потери строк, тест `[database]`.
- [ ] 2. Пересчёт v2 в приложении: очередь по строкам схемы 1 с файлом на диске, один декод на файл,
      отмена, запись `feature_schema=2`; тест на пропуск отсутствующих файлов.
- [ ] 3. `GlobalLinearModel` в C++: загрузка `model.v1`, стандартизация по `mu/sd`, матричное
      умножение, softmax, температура, `similarityMap`; отказ на битом файле и чужой схеме; тесты.
- [ ] 4. `AdaptiveClassifier`: две схемы, сравнение только внутри схемы, глобальная модель как
      `global_model`; локальные v2-прототипы; тесты приоритета и отсутствия NaN.
- [ ] 5. Резолвер и UI: источник `global_model`, About, показ источника типа без изменений.
- [ ] 6. Вклады и воркер: payload v2, приём обеих схем, экспорт обеих, согласие 4.
- [ ] 7. Поставка: `resources/ml/global_model.json` + атрибуция, `docs/`, `graphify update .`,
      полный `ctest` и `npm test`.

## Тесты и проверка

- C++ `[database]` миграция, `[ml]` загрузка модели, `[adaptive]` две схемы, `[contribution]` payload.
- Node: экспорт обеих схем, приём воркера, отчёт без путей.
- Ручная проверка: приложение с базой 15 запускается, старые типы работают, новые строки получают v2.

## Вне этапа

- Foley-модель и волна 2 датасетов — отдельно.
- Пересмотр критериев 7.6 — решение владельца по отчёту.
