# Ночная задача 2026-11-14: Normalize для выделения, горячие клавиши меню волны

Ветка: `feat/night-normalize-and-shortcuts`.

Задание владельца (сессия «Редактор волны: контекстное меню», 2026-11-14 03:00):

1. Починить переключение длинных сэмплов: предыдущий продолжает играть.
2. `Normalize (-0.1 dBFS)` для выбранных файлов в контекстном меню библиотеки, а не только в
   редакторе волны.
3. Настройка `Always overwrite original files`: без подтверждения сохранять и нормализовать.
4. Подсказки сочетаний в меню волны и работающие клавиши из одной таблицы команд.
5. `⇧⌘N` в контекстном меню библиотеки для Normalize выделенных.
6. Свериться с новыми ТЗ в `AGENTS.md`: взять из пакетного конвертера правила Normalize
   (−0.1 dBFS, один коэффициент на каналы, `no change` для тишины, безопасная запись через
   временный файл, потоковая обработка, переанализ без потери тегов). Экран переназначения
   клавиш и диалог Batch Processing ночью не делаются.

## Решения

- Оригинал не трогается до проверки временного файла; атрибуты файла переносятся.
- Тишина и файл, уже стоящий на цели, дают `unchanged`, а не запись.
- Форматы с записью: WAV/AIFF/FLAC. MP3/OGG и прочие — только копией в WAV.
- Сэмплы внутри контейнеров и образов дисков, файлы > 2 каналов и файл с несохранёнными
  правками в превью пропускаются с причиной.
- `Always overwrite original files` не отменяет диалог Save/Discard/Cancel при уходе с
  несохранённого файла: это защита от потери правок, а не подтверждение сохранения.
- Существующие сочетания (⌘S, ⌘Z, ⇧⌘Z, ⌘0, ⌫, Space, стрелки, Esc) не меняются.
