# E-mu EBL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** E-mu Emulator X `.ebl` samples become ordinary library audio: scanned, analysed,
previewed and dragged to a DAW as WAV, decoded bit-exactly as samplerdisc does.

**Architecture:** A pure decoder (`core/emu/EblReader`) ported from samplerdisc's documented
rules, wrapped as a `juce::AudioFormat` (`EblAudioFormat`). One function
`registerSonicatorFormats(juce::AudioFormatManager&)` replaces every `registerBasicFormats()` call,
so every existing reader path (analysis, preview, waveform, MIDI, export, split) gains `.ebl`
without per-feature code. Only two places are format-aware: the catalog name and the external drag.

**Tech Stack:** C++20, JUCE, Catch2 v3, CMake preset `release`
(`~/Library/Caches/sonicator-build/release`). samplerdisc via `uvx` for opt-in reference checks only.

**Spec:** `/Users/ilyaorange/.opencode/plan/2026-11-12-emu-ebl-tz.md`. Task 0 copies it to
`docs/superpowers/specs/2026-11-12-emu-ebl-design.md` and this plan to
`docs/superpowers/plans/2026-11-12-emu-ebl.md`.

## Global Constraints

- Layout rules are exactly the spec's: second section at BE u32 `0x1C`; block = second + 14;
  name UTF-16LE 64 bytes; V2 @+68, V3 @+72, rate @+100, V12 @+108 (all LE u32);
  stereo iff `((V12 >> 16) & 0xFF) == 0x03`; audio start `block + V2 − 4`; end = `EXLZ` offset
  (only if a full `MARK` follows: `mark + 16 ≤ size`) else EOF; length rounded down to 2 bytes;
  stereo per-channel `V3 − V2`, left start `end − 2·perChannel` if `perChannel > 0` and
  `start ≥ block + 176`, else midpoint split of `[audioStart, end)`; loop `MARK+8`/`MARK+12` LE,
  kept only if `0 ≤ start < end ≤ frames`.
- Every read is bounds-checked; a malformed file is refused with an error string, never a crash.
- Decoded size cap: 128 MiB per file (same as disc sources); larger is refused.
- `.ebl` files are opened read-only and never written.
- No Python in the app or in default tests; reference checks are `[.]` opt-in.
- Tests use temporary catalogs; the owner's `~/Library/Sonicator/sonicator.sqlite` is never touched.
- iCloud repo: before each commit `git ls-files | grep -E ' [0-9]+\.'` must be empty.
- Build `cmake --build --preset release`; tests `~/Library/Caches/sonicator-build/release/tests/SonicatorTests "<tag>"`.
- Branch `feature/emu-ebl`; finish: ff-merge into `main`, full `ctest`, push, delete branch.

## Review Focus

1. **Stereo end-anchor vs front-anchor**: a fixture whose front anchor would be 2 bytes off must
   decode correctly (Task 1).
2. **Truncated/garbled files**: header fields pointing past EOF, `V3 < V2`, huge `V2` — refused,
   no out-of-range read (Task 1, with a fuzz-style loop over truncations of a valid file).
3. **Format registration swap** must not change any existing reader: full `ctest` before and after
   Task 2 must both be green with the same test count.
4. **Catalog name**: an empty or all-space header name falls back to the file name (Task 3).
5. **Drag of a mixed selection** (`.ebl` + `.wav`): WAVs drag unchanged, `.ebl` become WAVs, a failed
   conversion is reported and does not drop the rest (Task 4).

### Task 1: The decoder

**Files:**
- Create: `core/emu/EblReader.h`, `core/emu/EblReader.cpp` (add to `CMakeLists.txt` core sources)
- Test: `tests/TestEblReader.cpp` (add to `tests/CMakeLists.txt`)

**Interfaces (produces):**
```cpp
namespace sonicator {
struct EblLoop { uint32_t start = 0, end = 0; };            // end exclusive
struct EblSample
{
    juce::String name;                                      // header name, trimmed; may be empty
    uint32_t sampleRate = 0;
    int channels = 0;                                       // 1 or 2
    int64_t frames = 0;                                     // per channel
    std::vector<int16_t> pcm;                               // interleaved, frames * channels
    std::optional<EblLoop> loop;
};
struct EblResult { std::optional<EblSample> sample; juce::String error; bool ok() const { return sample.has_value(); } };
EblResult parseEbl(std::span<const std::byte> bytes, uint64_t maxDecodedBytes = 128ull << 20);
EblResult readEblFile(const juce::File&, uint64_t maxDecodedBytes = 128ull << 20);   // whole file, size-capped
bool isEblFile(const juce::File&);                          // extension .ebl (case-insensitive)
}
```
- Errors: `"not a FORM"`, `"not an EBL (no E5B0TOC2)"`, `"first section is not E5S1"`,
  `"second section is not where the header says"`, `"data block runs past the end"`,
  `"sample rate is zero"`, `"no audio"`, `"decoded size exceeds the limit"`.
- `readEblFile` refuses files larger than `maxDecodedBytes + 64 KiB` before reading.

- [ ] **Step 1: tests** (`[ebl]`). A test-local builder
  `std::vector<std::byte> makeEbl({name, rate, channelByte, pad, frames, left[], right[], loop?, stereoFrontSkew})`
  writes FORM/TOC2/E5S1(second offset)/E5S1(14)/block/pad/audio/(EXLZ INFO MARK).
  Cases:
  - `mono with an 8-byte pad and a loop` → name, rate 47360, 1 ch, frames, pcm values exact, loop {2,6};
  - `mono with a 4-byte pad and no loop` → audio from block+180 to EOF;
  - `channel byte 0x02 is mono`;
  - `stereo is anchored from the end` → builder writes two extra bytes so `block+V2−4` lands 2 bytes
    early; expect interleaved L/R exact;
  - `truncated stereo falls back to a front split` → cut the file so `end − 2·perChannel < block+176`; expect ok, 2 ch, no crash;
  - `a loop outside the audio is dropped`;
  - refusals for each error string above (zero rate, bad magic, wrong TOC2, second-section offset past EOF, block past EOF);
  - `every truncation of a valid file is refused or decoded, never out of range` → loop `n = 0..size`, `parseEbl(first n bytes)` must return without crashing; when ok, `pcm.size() == frames*channels`.
