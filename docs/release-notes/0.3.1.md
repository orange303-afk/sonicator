# SONICATOR 0.3.1

0.3.1 is a correctness release for Windows: duplicate cleanup wrote a symbolic link, rejected the
link it had just created and restored the copy, so **Replace with links** never completed on that
platform. Everything else is the 0.3.0 feature set.

Each installer contains the application and, where it exists, the DAW plug-in. The Catalina package
leaves out ONNX Runtime, whose bundled library requires macOS 13.3; the application and plug-ins work
normally and the optional neural classifier falls back to the built-in acoustic rules.

## What changed since 0.3.0

- **Fix: Replace with links on Windows** — after creating the link, the cleanup compared the path the
  link reports with the kept original. Windows reports the long path while the temporary folder comes
  back in its 8.3 short form (`C:\Users\NAME~1\...`), so a correct link looked wrong: the action
  deleted it, restored the copy and reported a failure. Links are now verified by the file they
  resolve to (volume serial and file index on Windows, a normalised path elsewhere), so the action
  completes, the freed bytes are reported and the journal entry is cleared.
- **The Windows test gate proved itself** — since 0.3.0 the full Windows suite is a required check.
  The first runs failed on this defect, which the local machine could not see: without Developer Mode
  it skips the link tests. The fix ships with the suite green on Windows (1320 cases).

The catalog schema stays at 20; a 0.3.0 catalog opens without a migration.

## What is included

**macOS (universal, arm64 + x86_64, macOS 11 or newer)**
`SONICATOR-0.3.1-macOS-universal.pkg` — application, VST3 and AU. Components are selected
individually on the installer's customize screen.

**macOS 10.15 (Intel only)**
`SONICATOR-0.3.1-macOS-x86_64-10.15.pkg` — application, VST3 and AU. No ONNX Runtime.

**Windows (x64, Windows 10 or newer)**
`SONICATOR-0.3.1-Windows-x64.msi` — application and VST3. AU exists on macOS only.

**Linux (x86_64) — in development, may be unstable**
`SONICATOR-0.3.1-Linux-x86_64.AppImage` and `SONICATOR-0.3.1-Linux-amd64.deb` — the application
only; there is no VST3 plug-in for Linux yet. These are still an early preview: audio devices, DAW
drag-and-drop, HiDPI and Wayland remain unverified by the owner.

Install locations: `/Applications/SONICATOR.app`, `/Library/Audio/Plug-Ins/VST3`,
`/Library/Audio/Plug-Ins/Components` on macOS; `Program Files\SONICATOR` and
`Program Files\Common Files\VST3` on Windows; `usr/bin/SONICATOR` and `usr/lib/sonicator` for the
Linux package. The library, settings and exported audio are never touched by install, upgrade or
uninstall.

## Signing and Gatekeeper

The packages are **unsigned**: no Developer ID, no Apple notarization, and the macOS bundles carry an
ad-hoc signature. The Windows installer has no Authenticode signature, and the Linux packages have no
signature and no distribution repository. macOS may block the `.pkg` — use *System Settings → Privacy
& Security → Open Anyway* after the first attempt; Windows SmartScreen may warn — use *More info → Run
anyway*. The installers remove the quarantine attribute from SONICATOR's own bundles only.

## Verified

CI on disposable runners installs the packages, starts the installed application, validates the
plug-ins with `pluginval` at strictness 10, runs `auval` for the native AU slice and reinstalls while
checking that the catalog, preferences and exported audio are unchanged. The Windows job runs the full
suite and gates the branch; on this release it covers the link replacement with an elevated test that
creates real symbolic links. The Linux job runs the suite under Xvfb and checks the package layout and
dependencies.

## Known limits

- The Type and structure filters apply to the list; the Cloud view keeps showing every tagged file.
- Type and structure come from the analyzer or a manual correction; the application does not guess,
  so an unclassified file stays in the library when both structure filters are on.
- A Windows taskbar pin created under 0.1.0 can keep its blank image until it is recreated.
