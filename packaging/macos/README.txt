SONICATOR — application, VST3 and Audio Unit

This installer is unsigned and is not notarized by Apple. Its application and
plugins carry ad-hoc signatures, not a Developer ID signature.

macOS may block the installer itself. After attempting to open it, use System
Settings > Privacy & Security > Open Anyway if macOS offers that option, and
confirm that you trust this download. Organization security policy may prohibit
unsigned software. This installer does not change global security settings.

After you approve installation, the selected components have their quarantine
attribute removed automatically. No Terminal command is normally needed for
the installed application/plugins. This is not a guarantee of approval by all
macOS or DAW security policies.

Quit SONICATOR and your DAWs before upgrading. Use Customize to select components.
The application owns the library: run it first to create/update the catalog,
then open the plugin in your DAW. Restart/rescan the DAW after installation.

The installer does not delete your library, settings or exported audio.
